# Идеи — агенту

Мобильное PWA-приложение: асинхронный чат с агентом. Идеи можно отправлять, даже когда компьютер выключен.

## Как это работает

- Приложение устанавливается на телефон (Chrome: «Установить приложение», iPhone: «Поделиться» → «На экран „Домой“»).
- Идеи сохраняются локально и синхронизируются с приватным GitHub-репозиторием.
- Когда компьютер включён, агент читает новые идеи и отвечает в тот же чат.
- Ответы появятся в приложении после синхронизации.

## Первичная настройка

1. Создать fine-grained токен GitHub: Settings → Developer settings → Personal access tokens → Fine-grained tokens.
2. Repository access: Only select repositories → репозиторий с идеями.
3. Repository permissions → Contents: Read and write.
4. Открыть приложение → шестерёнка → вставить токен → «Готово».

Токен хранится только в localStorage телефона и не попадает в исходники.

## Разработка

Статическое приложение без сборки: `index.html`, `styles.css`, `app.js`, `manifest.webmanifest`, `sw.js`.
